# 🎓 Online Course Registration System (MERN Stack)

A full-stack web application for managing online course registrations with user and admin roles.

---

##  Features

### 👨‍🎓 User Features
- User registration & login
- Browse available courses
- Enroll in courses
- View profile & enrolled courses

### 🛠️ Admin Features
- Add new courses
- Edit & delete courses
- View all users
- Manage course listings

---

## 🧑‍💻 Tech Stack

- Frontend: React (Vite), JavaScript, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- API: REST API
